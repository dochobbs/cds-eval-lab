# CDS Eval Lab

A physician-built evaluation harness for clinical decision-support AI.

**Live site:** https://dochobbs.github.io/cds-eval-lab/

This repo holds the public-facing site that describes the harness, the
benchmark stack, and the blinded results. The harness itself, the query
sets, the judge prompts, and the vendor-attributed reports are kept
private.

## What's here

- `docs/index.html` — single-page brochure
- `docs/assets/styles.css` — bold technical brochure styling
- `docs/assets/render.js` — renders the page from `data.json`
- `docs/assets/data.json` — blinded leaderboard, suites, queries, findings

## What's not here

- Real vendor names
- Full query text
- PHI, raw clinical traces, or active research drafts
- Anything from the PEARL workstream
